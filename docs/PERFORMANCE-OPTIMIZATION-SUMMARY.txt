═══════════════════════════════════════════════════════════════════════════════
                            THE PROBLEM
═══════════════════════════════════════════════════════════════════════════════

Users reported continuous API calls every second in audit fieldwork module:
  • 5 concurrent API calls per page view
  • Calls triggered continuously despite no data changes
  • Network tab showing 50+ requests per minute
  • Global rate limiting being hit (100 req/min limit exceeded)
  • Page becoming sluggish and unresponsive

Root Cause Analysis:
  ✗ Frontend watchEffect calling fetchAllFieldworkData() repeatedly
  ✗ No Kong-level response caching
  ✗ No request deduplication on frontend
  ✗ Unnecessary refetch calls after save operations
  ✗ No endpoint-specific rate limiting

                            QUICK REFERENCE
═══════════════════════════════════════════════════════════════════════════════

Response Headers You'll See:
  X-Cache: HIT              → Response from Kong cache (very fast)
  X-Cache: MISS             → Fresh from backend (normal speed)
  X-Cache: BYPASS           → Not cacheable (POST/PUT/DELETE)
  X-RateLimit-Limit-Minute: 60
  X-RateLimit-Remaining-Minute: 45
  Retry-After: 30           → Wait 30 seconds before retrying

Cache Behavior:
  GET /api/v1/fieldwork/interviews → Cached for 5 minutes
  POST /api/v1/fieldwork/interviews → Not cached, invalidates related cache
  PUT /api/v1/fieldwork/interviews/{id} → Not cached
  DELETE /api/v1/fieldwork/interviews/{id} → Not cached

Rate Limiting:
  Production: 60 req/minute per IP
  Development: 300 req/minute per IP
  Returns: 429 Too Many Requests when exceeded
  Auto-retry: Check Retry-After header

Troubleshooting:
  Problem: Stale data after update
  Solution: Call store.invalidateFieldworkDataCache() or wait 5 minutes

  Problem: Rate limit 429 errors
  Solution: Check frontend for infinite loops, respect Retry-After header

  Problem: Cache not working (X-Cache: MISS every time)
  Solution: Verify Kong config reloaded, check query parameters match
