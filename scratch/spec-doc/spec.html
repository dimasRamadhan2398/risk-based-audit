BAGIAN A — TECH STACK APLIKASI

A.1 Gambaran Arsitektur

AuditSphere dibangun dengan arsitektur microservices. Antarmuka web (Nuxt) berkomunikasi melalui satu pintu, yaitu API Gateway (Kong), yang meneruskan permintaan ke layanan backend berbasis Go. Setiap layanan memiliki basis data PostgreSQL sendiri, berbagi cache Redis, dan saling bertukar event melalui Apache Kafka. Fitur analitik dan prediksi risiko dijalankan oleh layanan AI terpisah berbasis Python.
