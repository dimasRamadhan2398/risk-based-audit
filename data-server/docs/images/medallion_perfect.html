2. Data Lakehouse Architecture (PostgreSQL 16 Multi-Zona)

Bronze (Raw Append-Only) ➔ Silver (Cleaned & Validated) ➔ Gold (Star Schema, CAATT & AI Predictions)
MEDALLION PIPELINE
BRONZE ZONE (Raw Storage)
Role: etl_user (CRUD)
Data mentah append-only persis seperti aslinya dari sistem sumber. Tidak ada validasi tipe data ketat untuk mencegah data drop.
Tabel Skema bronze.*:
• bronze.cbs_transactions_raw
• bronze.cbs_accounts_raw
• bronze.cbs_customers_raw
• bronze.sync_master_companies
• bronze.sync_master_departments
• bronze.sync_risk_registers
Ingest via: Data Hub API (:8100) • dlt Ingestion
SILVER ZONE (Cleaned & Validated)
dlt / Python ETL
Pembersihan data, type casting (tipe data eksplisit), deduplikasi transaksi, normalisasi model relasional & integritas referensial.
Tabel Skema silver.*:
• silver.cbs_transactions_clean
• silver.ref_customers & ref_accounts
• silver.ref_products & ref_branches
• silver.ref_companies & ref_depts
• silver.ref_risk_categories
• silver.audit_working_papers_norm
Proses: Deduplication • Cast Types • Referential Checks
GOLD ZONE (Star Schema + 50 Views + CAATT + AI)
Role: auditor_ai (Read-Only)
Data analitik teragregasi tingkat tinggi, Star Schema bisnis, hasil pengujian CAATT, dan prediksi model AI yang siap dikonsumsi langsung.
Star Schema Facts & Dims:
• fact_transactions
• fact_loans
• fact_gl_entries
• dim_customers
• dim_accounts & dim_depts
CAATT & AI Predictions:
• caatt_full_population_results
• caatt_duplicate_gap_results
• caatt_benford_results
• ai_risk_score_predictions
• ai_anomaly_predictions
Akses: High Performance Star Schema • 50+ Specialized Views • Read-Only Enclave
